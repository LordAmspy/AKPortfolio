05 — Evaluation

I measure the system, not just the demo

For RAG and agentic systems, evaluation is split across retrieval, generation, task execution, and production behavior. A fixed golden dataset makes regressions repeatable instead of subjective.

01 · GOLDEN DATASET

Known questions. Known evidence. Known expectations.

Curated evaluation cases pair a user query with expected answers, relevant source documents or chunks, and acceptable refusal behavior. The same cases can be replayed after changes to chunking, embeddings, retrieval, prompts, models, or agents.

Query→Gold Context→Gold Answer→Expected Behavior
02 · RETRIEVAL EVALS

Did the right evidence arrive?

Recall@KRelevant evidence found in the top K results
Precision@KHow much of the retrieved context is useful
MRRHow early the first relevant result appears
nDCG@KQuality and ordering of graded relevance
Context RecallWhether retrieved evidence covers the answer requirements
03 · GENERATION EVALS

Did the model use the evidence correctly?

FaithfulnessClaims supported by retrieved context
Answer RelevanceWhether the response actually answers the query
CorrectnessAgreement with the expected answer or task outcome
Citation QualityWhether cited evidence supports the associated claims
04 · AGENT & PRODUCTION

Did the workflow behave reliably?

Task SuccessWhether the complete agent workflow achieves the intended outcome
Guardrail Violation RateFrequency of responses outside defined constraints
LatencyEnd-to-end response and tool execution time
Cost / RequestModel and tool usage per successful task
Regression RateCases that fall below an evaluation threshold after a change
EVALUATION LOOP
